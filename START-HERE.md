# Start here, Shiloh

This folder is your HQ. It's a set of notes that live on your PC and back up to GitHub.
COLT (in Grok) reads them to know where you are. Claude tidies them up every night at 8 pm.
Do this once, with Dad. It takes about 30 minutes.

## 1. Accounts (with Dad)
- [ ] Make a GitHub account at github.com. Use a username that isn't your full name.
- [ ] Turn on two-factor sign-in (GitHub → Settings → Password and authentication).
- [ ] Dad adds you to the `homeschool-os` repo (Settings → Collaborators). Accept the email invite.

## 2. Get the HQ onto your PC
- [ ] Install **GitHub Desktop** (desktop.github.com) and sign in.
- [ ] File → Clone repository → `homeschool-os` → save it to `Documents\Shiloh HQ`.
- [ ] Top bar → Current branch → switch to **`post-grok`**. (`main` is the old web app. Don't work there.)

## 3. Open it in Obsidian
- [ ] Install **Obsidian** (obsidian.md).
- [ ] "Open folder as vault" → pick `Documents\Shiloh HQ`. Trust the author when it asks.
- [ ] Settings → Community plugins → turn on → Browse → install **Obsidian Git** → enable.
- [ ] In the Obsidian Git settings: auto pull on startup = on; auto commit-and-sync every 10 minutes.
- [ ] Open the graph view (Ctrl+G) and look around.

## 4. Meet COLT
- [ ] Open the Grok "Shiloh HQ" project Dad set up. Say: **"COLT, morning."**
- [ ] If you want, give COLT a new name (Doc 06 §8).

## Every day
| When | What you do |
|---|---|
| Morning | "COLT, morning" → do the first move it suggests |
| Working | "teach me <course> unit N" · "hey <mentor>" |
| Finished something | "I finished <thing>" |
| End of day | "COLT, wrap up" → paste any HANDOFF block into a new note in `handoff/inbox/`, then Ctrl+P → "Git: Commit and sync" |
| Friday | "weekly review", then show Dad |

## Good to know
- **What's private:** just talking with COLT (feelings, friends, worries) is never written down.
  Your finished work, quizzes and missions *are* tracked. That's your evidence.
- You decide your mentor seats and COLT's name. Changes to the rules go through Dad.
- If you see a "merge conflict", don't panic. Stop and get Dad.
