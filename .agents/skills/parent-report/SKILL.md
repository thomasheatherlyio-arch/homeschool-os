Audience: **Thomas only.** Read `55-progress/hs-readiness.md`, `55-progress/verifications.md`,
`55-progress/diagnostics.md`, the newest weekly note's "For Dad", NOW.md, and the front matter of the
period's `50-evidence/` notes. Never read or report "just talking".

Output exactly this shape (≤40 lines):
1. **Headline**: on track / watch / off track for the target 9th-grade start, and why (one sentence).
2. **Gates**: Gate 1 subjects that changed (status, level, verified/pending); Gate 2 streak; Gate 3 credits.
3. **Verified vs claimed**: N verified this period, N pending. Never describe pending work as done.
4. **Waiting on you to verify**: each pending item with a 2-minute check (see `verify-evidence`).
5. **System health**: missions done/total, daily notes count, open loops at stage 2–3.
6. **Risks**: a subject flat 4+ weeks, missed deadlines, no evidence.
7. **Decisions for Thomas**: targets, HS start date, credits, proposals waiting.
8. **Talk with Shiloh**: one coaching question (diagnose the system, not the kid).
