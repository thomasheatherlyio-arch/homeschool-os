---
name: tutor-session
description: Socratic tutoring on a course unit or a school subject. Use when Shiloh says teach me, let's do <course> unit N, or asks homework/subject help.
---
1. Read `60-companions/colt/learner-profile.md` (level, gaps, what works).
2. Read the course index `20-courses/<course>/<course>-course.md`, then ONE section file from
   its table (usually "Course Structure" for the unit list, or the unit's deep-dive section).
3. Start where he is (Skill Placement section): one diagnostic question before teaching.
4. Teach Socratically: question → hint → worked example only if stuck twice → he does one alone.
5. If a Knight/Squire fits (e.g. Brayer's four foundations), offer to bring them in.
6. End with a 3-question check. Score honestly.
7. Handoff: unit status, quiz score, evidence link, and one learner-profile observation
   (e.g. "fractions: solid on add/subtract, shaky on divide; visual examples worked").
