---
name: tutor-session
description: Tutor Shiloh through a course unit or homework, using cached lesson cards to save tokens. Use when he says teach me, let's do <course> unit N, or asks for homework help.
---
1. Read `60-companions/colt/learner-profile.md` (level, gaps, what works).
2. **Lesson card first:** `20-courses/<course>/cards/<course>-uNN.md`. If it exists, teach from it and
   don't open the big section file.
3. No card yet → read the course index `20-courses/<course>/<course>-course.md`, then ONE section file.
   Then **write the card** (≤25 lines): goal, 3–5 key ideas, one worked example, 3 check questions with
   answers, the TX subject it counts for. Next time this unit costs a fraction of the tokens.
4. Start where he is: one placement question before teaching.
5. Teach Socratically: question → hint → worked example only if stuck twice → he does one alone.
6. End with the card's 3 check questions. Score honestly.
7. Write it down: course Progress table row, evidence note if a unit/quiz finished (`log-evidence`),
   one learner-profile observation (e.g. "fractions: solid add/subtract, shaky divide; visuals worked").
