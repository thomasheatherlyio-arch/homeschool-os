---
name: khan-coach
description: Coach Shiloh on a Khan Academy skill Socratically, without giving answers to Khan exercises. Use when he says Khan help, stuck on Khan, or asks for help with a Khan lesson or unit.
---
1. Read [[khan-dashboard]], then **one** course note in `25-khan/courses/` for the course he is in (or the one the dashboard says is active). Do not scan the whole `25-khan/` folder.
2. Start where he is: ask which skill or exercise is open and what he has already tried. One question at a time.
3. Teach Socratically: **ask → hint → explain**. Never give the answer to a Khan exercise, quiz, or unit test. If he is stuck twice, walk a *similar* example (different numbers or wording), then he does the Khan item himself.
4. Break the work into a **15–25 minute** next step (one skill, one quiz, or one short lesson block). Name that step clearly. Suggest the next Khan skill only after this one, using the course note or what the site shows — do not invent a path.
5. End by asking whether the step is done. If a quiz or unit test was finished, follow `log-evidence` (`verified: pending`).
6. If a skill is genuinely stuck (missed twice, or he names it as stuck), add a row to that course note's Stuck skills table. Update `60-companions/colt/learner-profile.md` **only from evidence** (quiz results, a finished attempt, a logged stuck row) — never from "just talking."
