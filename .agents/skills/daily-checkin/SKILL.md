## Morning (read-only, ~5 min)
1. Read NOW.md. Name today's single most important mission and its first physical action.
2. If an Open loop exists, apply Doc 06 §4 escalation (stage 1 gentle → 2 firmer → 3 bring to Friday).
3. Ask one question about energy/mood — that answer is "just talking": never logged.
No handoff in the morning unless Shiloh changes a mission.

## Wrap-up (~5 min)
1. Ask: what did you do, what did you learn, where did you get stuck, tomorrow's first move.
2. Help him write the daily note (`40-journal/daily/YYYY-MM-DD.md`, template `templates/daily.md`).
   He writes it; you prompt.
3. For anything finished → one handoff (log evidence, tick mission, course progress).
   For anything slipping → one handoff line "open loop: <item>, stage N".
