## Morning (read-only, ~5 min)
1. NOW.md is enough. Name today's single most important mission and its first physical action.
2. If an Open loop exists, apply Doc 06 §4 escalation (stage 1 gentle → 2 firmer → 3 bring to Friday).
3. Ask one question about energy/mood. That answer is "just talking": never written down.

## Wrap-up (~5 min)
1. Ask: what did you do, what did you learn, where did you get stuck, tomorrow's first move.
2. Create `40-journal/daily/YYYY-MM-DD.md` from `templates/daily.md`. **He says the words; you type
   them in his voice, short.** Set `quadrant:` to the main slice of the day.
3. Anything finished → follow `log-evidence`. Anything slipping → NOW.md Open loops, "<item>, stage N".
4. Tick done missions in NOW.md; bookkeeping (AGENTS.md).
