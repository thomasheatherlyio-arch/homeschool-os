1. One subject per sitting, about a week apart, never batched (Doc 09a §2).
2. Write the packet for Thomas to `55-progress/packets/<subject>-<date>.md`: tiers of 5 items starting
   **Tier 2** (~6th grade) for a baseline, or one tier below the last level for a re-check; answer key;
   stop rule (stop a tier after 3 misses). Thomas prints it. **Don't show it to Shiloh; no AI help during it.**
3. Thomas reports results → score with the rubric: Level 0–4, grade-equivalent, one-line ceiling note.
4. Ask Thomas + Shiloh for the target level (Doc 09a §5 step 5).
5. Write: a row in `diagnostics.md`; Baseline/Now/Target in `hs-readiness.md`; Current levels in
   `learner-profile.md`; an evidence note (`verified: pending`, Thomas confirms it in verifications.md);
   the gap into next week's missions.
