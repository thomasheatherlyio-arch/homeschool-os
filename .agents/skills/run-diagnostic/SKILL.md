1. One subject per sitting, about a week apart, never batched (Doc 09a §2).
2. Build the packet for Thomas (not Shiloh): tiers of 5 items, starting **Tier 2** (~6th grade) for a
   baseline, or one tier below the last level for a re-check. Include an answer key and the stop rule
   (stop a tier after 3 misses). Thomas gives it on paper; no AI help for Shiloh during it.
3. Thomas reports the results → score with the rubric: Level 0–4, grade-equivalent estimate, one-line
   ceiling note ("solid through fractions; ceiling at percent word problems").
4. Ask Thomas + Shiloh for the target level (Doc 09a §5 step 5).
5. Handoff to Claude: add a row to `55-progress/diagnostics.md`; update `hs-readiness.md` (Baseline/Now/
   Target) and `learner-profile.md` (Current levels); add an evidence note (`verified: yes`,
   `how_verified: diagnostic`); put the gap into next week's missions via NOW.md.
