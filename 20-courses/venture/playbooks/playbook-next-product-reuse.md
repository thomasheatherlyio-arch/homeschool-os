# How to Reuse This Kit for Your Next Product

Linked to: [[playbooks-index]] | [[playbook-persona-creation]] | [[shiloh-playbook]]

## Purpose
Turn any future project from Forge, Kitchen, Gym, Civ, or Venture into a repeatable micro-business in one afternoon of setup—without reinventing your workflow.

## When to Use
- You finish or pause your current venture and want to test Venture #2.
- You build a cool internal script, study tool, or template and ask: *"Would other families or teens buy this?"*

## Step-by-Step Instructions
1. **Create a New Product Folder**: Under `20-courses/venture/`, make a unique kebab-case folder (e.g., `20-courses/venture/<product-slug>/`). Never edit the playbooks themselves unless improving the template for *all* future products.
2. **Copy the 3 Core Project Notes** (and rename with `<product-slug>-*` prefixes so filenames stay unique across the vault):
   - `<product-slug>-dashboard.md`
   - `<product-slug>-brief.md`
   - `<product-slug>-roadmap.md`
3. **Run Playbook #1 First (Hard Gate)**: Score the new idea with [[playbook-idea-research-scorecard]]. If it scores **under 60/100**, park it in an ideas backlog and pick a stronger idea.
4. **Submit a Proposal**: Draft a <=15-line note in `proposals/` (`decision: pending`) for Thomas to greenlight the new project and its <$25 experiment budget.
5. **Run Playbooks 2 -> 9 in Order**: Never build a landing page or code an app (Playbook 3–4) before completing at least 5 real conversations or a <$25 smoke test (Playbook 2).
6. **Reuse or Confirm the Persona**: Default to the existing Dad-approved [[playbook-persona-creation|persona]] and Dad-held brand accounts. Create a new handle only if Thomas approves a clear reason; never put real name, face, location, school, or personal accounts on the new product.
7. **Reuse Your Parent Infrastructure**: Keep using Thomas's existing LLC/sole-prop, Gumroad/Stripe guardian setup, and legal templates from [[playbook-legal-setup]]—just add a new product SKU, confirm trademark search on the **brand** (not a personal name), and run a product-specific EULA/privacy check.

## New Venture Kickoff Checklist
- [ ] Folder `20-courses/venture/<product-slug>/` created with unique kebab-case filenames
- [ ] Scorecard >= 75/100 (or 60–74 with explicit risk-test plan)
- [ ] Proposal note submitted with `decision: pending`
- [ ] <$25 weekend validation experiment defined before writing code
- [ ] Approved persona confirmed (or a new handle explicitly approved by Dad)
