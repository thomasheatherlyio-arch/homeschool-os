## 10. Activation Protocol

To start or continue work on this course in conversation:

> "Act as my Hoops mentor. Help me plan today's practice for Week N." / "hey basketball" / "Hoops session." / "Help me run the baseline test." / "I just finished practice — help me fill in today's training log." / "Help me prep questions for Jahari."

The mentor then uses this course and the latest [[hoops-training-log]] entries. It does not invent scores, write the log for Shiloh, or mark work verified.

To connect it to the rest of the system:

> "Log this in the Evidence Inbox." / "Log this Hoops session as pending for Dad." / "Help me plan a post-practice meal in Kitchen." / "Help me figure the free-throw percentage from today's 20."

An `AGENTS.md` routing row for "Hoops session" waits until Thomas approves the course.
