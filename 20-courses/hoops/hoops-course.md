# The Hoops: Basketball Fundamentals & AAU Tryout Prep

**Purpose:** Shiloh has asked for a structured basketball track — not pickup as a substitute for training, but a time-boxed fundamentals course aimed at an **AAU team tryout in early 2027** (January–February window; exact date not yet set), the same way [[gym-course|Doc 15]] turns training science into a course and [[kitchen-course|Doc 14]] turns cooking into a course. This doc builds that: a baseline skill-placement test, a 10-week plan from late November 2026 through late January 2027, and written logs Thomas can actually check. On-court work is the workshop; the other half is tying that work into the rest of the curriculum — [[gym-course|Gym]] / [[body-discipline]] (PE hours), [[kitchen-course|Kitchen]] (athlete nutrition and meal prep), [[panel-course|Panel]] / [[mind-mastery]] (film study, shooting-percentage math, journaling), [[shiloh-playbook|Venture]] (training log as a real artifact; optional teaching or content later), and [[civ-course|Civ]] / [[spirit-character]] (teamwork, coachability, sportsmanship).

This course runs **alongside, not instead of**, Shiloh's existing basketball work with Jahari ([[jahari]], [[02-knights-of-the-round-table|Doc 02]]) and the science-of-training work in [[gym-course]]. Jahari coaches in person; the [[basketball|Hoops mentor]] helps plan practices, run the baseline, and close each session with evidence. The Gym course still owns physiology, program design, and the flat-feet protocol.

## How a session works (read this with Sections 4–6)

- **Practice is time-boxed** (about 45–75 minutes, plus a real warm-up and cool-down). A session **counts as course work only when** a log entry is written the same day (copy the block from [[hoops-training-log-template]] into [[hoops-training-log]]). Optional video or a photo of a written scoresheet goes in `50-evidence/` with the path pasted in the log.
- **At least one full rest day each week** from organized basketball (see [[hoops-11-sources|Sources]] — USA Basketball youth guidelines). Week 5 (Christmas week) is a lighter maintenance week, not a peak-load week.
- **Safety sits with Dad and Jahari**, not with the mentor. Follow the [[gym-course|Gym]] warm-up / mobility and flat-feet work already in that course. No max-lift testing, no invented "elite" times, no supplements unless Dad has approved them.
- **Clock times stay draft** until Shiloh and Dad approve them in [[shiloh-schedule]]. Do not add calendar blocks before that.
- **"Hoops session" routing.** Shiloh tells the [[basketball|Hoops mentor]] (or COLT using that seat): *"Hoops session"* / *"hey basketball"* / *"I finished my baseline."* The mentor plans or debriefs; it does not write the log for him or mark work verified. *(An `AGENTS.md` routing line waits on Dad's approval of this course.)*
