## 12. Getting Started

A low-stakes first move: run the Skill Placement check (Section 5) with COLT, then start Unit 1 with one simple, real dish — nothing elaborate, just knife basics, a hot pan, and a safety checklist he builds himself. See how the first afternoon actually feels before locking in a longer pace.
