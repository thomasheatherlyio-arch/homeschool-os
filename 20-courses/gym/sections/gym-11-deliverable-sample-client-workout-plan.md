## 11. Deliverable — Sample Client Workout Plan

A full program written the way a working personal trainer would actually write one for a new client — the direct Capstone dress rehearsal (Section 12). Client profile assumed below is a generic healthy adult beginner; Shiloh should rebuild this same structure around whoever his real first client turns out to be (himself, Thomas, or another family member), adjusting load and exercise selection to that person's actual starting point per Unit 7's assessment step.

**Client profile (example):** Healthy adult, beginner training experience, general strength/fitness goal, no current injuries, available 4 days/week, 45–60 minutes per session.

**Program overview:** 4-day upper/lower split, 4 weeks, built on the progressive overload rule from Section 7 — when all sets hit the top of the rep range with good form for two sessions in a row, add weight and return to the bottom of the range. Every session opens with the Section 10.1 dynamic warm-up and closes with the Section 10.2 cool-down.

| Day | Focus | Exercise | Sets × Reps | Rest |
|---|---|---|---|---|
| **1** | Upper Body — Push/Pull | Push-ups (or bench press) | 3 × 8–12 | 90 sec |
| | | Dumbbell rows | 3 × 8–12 | 90 sec |
| | | Overhead press | 3 × 8–10 | 90 sec |
| | | Lat pulldown or assisted pull-up | 3 × 8–10 | 90 sec |
| | | Plank | 3 × 30–45 sec | 60 sec |
| **2** | Lower Body — Strength | Bodyweight or goblet squat | 3 × 10–12 | 2 min |
| | | Romanian deadlift | 3 × 8–10 | 2 min |
| | | Walking lunges | 3 × 10 each leg | 90 sec |
| | | Calf raises (arch-focused, per Section 9) | 3 × 12–15 | 60 sec |
| | | Dead bug (core) | 3 × 10 each side | 60 sec |
| **3** | Active Recovery / Conditioning | Brisk walk, bike, or easy jog | 20–30 min continuous | — |
| | | Core circuit (plank, side plank, bird-dog) | 2 rounds | 30 sec between |
| | | Full mobility/stretch session (Section 10) | 10 min | — |
| **4** | Full Body / Accessory | Kettlebell or dumbbell swings | 3 × 12–15 | 90 sec |
| | | Step-ups | 3 × 10 each leg | 90 sec |
| | | Push-up variation | 3 × max quality reps | 90 sec |
| | | Single-leg balance (flat-feet carryover, Section 9) | 3 × 20–30 sec each foot | 60 sec |
| | | Farmer's carry | 3 × 30–40 yards | 90 sec |

**Progression note for weeks 2–4:** apply the Section 7 progressive overload rule to every exercise independently — some movements will progress faster than others, and that's expected and normal, not a sign something's wrong with the program.
