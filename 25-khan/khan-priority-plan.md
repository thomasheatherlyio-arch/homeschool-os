### What "done" means for a unit
A unit is **done** when a Friday sync shows **mastery ≥ 80%** *or* a **unit test passed**. File tests as pending evidence. Do not mark a unit done from memory.

### Session size
Every sitting is **15–25 minutes** (the 25- and 20-minute blocks above). One skill, one quiz, or one short lesson — not a whole unit in one go. If stuck twice, tell COLT **"Khan help"** (ask → hint → explain; no answers to Khan exercises).

## How it fits the week

- **Monday planning:** put the nine blocks on the week (4 ELA, 3 science, 2 math). Name the first 15–25 minute move.
- **During the week:** time-boxed sessions; same-day note if a quiz or unit test is finished (`log-evidence`, pending).
- **Friday ~6 PM — automatic Khan sync** (see [[25-khan/README|README]] and the khan-sync skill), so Dad can look over the weekend. COLT writes the snapshot, updates the dashboard and course notes, and writes the weekly Khan log. This is the same Friday as the usual weekly review with Dad ([[NOW]]).

Holiday weeks (late December) may be lighter; skip or shrink blocks rather than invent catch-up numbers.
