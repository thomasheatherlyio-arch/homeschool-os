# Key — Executive function (COLT / Dad only)

Shiloh should not open this file before or during a sitting. COLT never reads a key aloud during a test.

**Scoring principle:** Self-report items have **no single correct personal answer** and are not a character test or a medical screening. Score completeness, honesty, and a workable next step. A truthful "I usually don't leave a next step; here is one change" can earn a 2. A polished but empty answer ("I should focus more") should not. Never invent a skill level or diagnosis from these items.

**Points:** E6 = 1 or 0. All other items = 2 complete and workable, 1 partial, 0 blank or only self-criticism with no plan. **Total: 22 points.**

### E1
A 2 names a real recent task, describes how it started (not only "I did it"), and names a keep-going help (timer, first small step, a checklist, a person, a written goal). Vague "I just worked" is a 1.

### E2
A staged 25-minute plan that includes start (materials / first problem), work time, a check, and an end, plus a definite moment to write the two questions (not "if I have time"). 1 if the questions or the ending are missing.

### E3
A 1–5 rating, one concrete example (even "I don't remember an exact time, but last week the writing took longer than I thought"), and one tactic (try a 10-minute sample, break the job into parts, compare estimate vs. actual on a log). A rating with no example or tactic is a 1.

### E4
First two minutes: clear only what blocks the work, refill only if it takes seconds or skip it, sit, open the assignment. Deliberately not: reorganizing the whole desk, starting a side chore, wandering to the kitchen for a long refill, or "quickly" checking unrelated tabs. 1 if the plan spends the whole 20 minutes tidying.

### E5
If-then form is used. The action is specific and same-day (mute, close the tab, say "after this block," write the interruption down). The return point is the exact next step of the work, not "try harder." 1 if it is only a slogan.

### E6 — **Correct: C.**

### E7
A sensible order (often a short job first to start, or the harder short job while energy is higher — either can work if reasoned). The long job gets a start or a written next step so it does not vanish. 1 if the long job is ignored with no note.

### E8
Two workable options, each with a recorded next step, for example: (1) finish the problems you can, star the two hard ones, and write a question for Dad; (2) spend ten focused minutes on one hard problem, write what you tried, and list what remains; (3) switch to the easiest remaining items and calendar the hard ones. "Quit and hope" with no record is not a 2. The chosen option needs a because that is practical.

### E9
Describes the usual close (or honestly admits a scatter) and includes materials and/or a written next step. If the habit is weak, one specific weekly change is required for a 2 ("I will leave the worksheet on top with a sticky 'start at #7'").

### E10
A standup note with all three parts: what got done (science, maybe how far), what did not (the paragraph), and the first action next time (open the draft, reread the last science question, etc.). 1 if a part is missing.

### E11
A sequence (for example, stalled subject second after an easy warmup, or stalled subject first while fresh) plus a flex rule (if the stalled subject still has an unfinished start, flex continues it; if it is complete, flex is a break or the third task). The reason talks about startup or energy. "Do the easy one forever" with no rule for the stall is a 1.

### E12
A real tool and an exact next-step sentence for work that is actually open (or "no school work is open; tonight's next step is X"). "Remember to work" is too vague for a 2.
